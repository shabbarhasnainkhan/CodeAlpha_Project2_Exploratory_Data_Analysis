# CodeAlpha Internship – Project 2

## 📊 UK Data Analyst Job Market – Exploratory Data Analysis

This project is part of my **CodeAlpha Data Analytics Internship**.

The aim of this project was to explore a dataset of UK Data Analyst job postings collected from **Reed.co.uk** during Project 1. The analysis focuses on understanding the dataset, finding patterns and trends, and identifying potential data quality issues.

## 📌 Project Overview

The dataset contains **377 UK Data Analyst job postings** with the following information:

- Job Title
- Company
- Location
- Salary
- Skills
- Job URL

The analysis was carried out using **Python and Pandas**, with Matplotlib used for visualisation.

## 🔍 Analysis Performed

The project includes:

- Exploring the dataset structure and data types
- Checking missing values and duplicate records
- Cleaning job titles by removing locations included in the title
- Preparing salary data for analysis
- Analysing job titles and role levels
- Analysing job locations
- Exploring salary distribution
- Identifying commonly requested technical skills
- Identifying unusual salary values and other data quality issues
- Creating visualisations to highlight key patterns

## 📈 Key Findings

- **377** job postings were analysed.
- **London** had the highest number of job postings, with **102 listings**.
- **208** postings contained the word "Trainee" in the job title.
- **299** postings included salary information.
- The average annual salary in the prepared salary data was approximately **£43,320**.
- The median annual salary was **£40,000**.
- Technical skills such as **R, SQL, Python, Excel and Power BI** were commonly requested.
- Some salary values used different pay formats, so these were treated separately during salary analysis.
